## Цель работы

Нужно сделать простой тестовый фреймворк на аннотациях и рефлексии.
Фреймворк сам находит методы с `@Before`, `@Test` и `@After`, запускает их и в конце пишет, сколько тестов прошло, сколько упало и сколько было всего.

## Алгоритм работы, описание методов

В пакете `org.example.annotation` лежат три аннотации: `@Before`, `@Test` и `@After`.
У всех стоит `@Retention(RUNTIME)`, чтобы раннер мог увидеть их через рефлексию, и `@Target(METHOD)`, чтобы ими можно было помечать только методы.

`MathClass` — обычный класс с арифметикой: сумма, умножение и деление. Если делить на ноль, метод бросает исключение.

`MyClassTest` — класс с тестами. Перед каждым тестом вызываются `before1` и `before2`, после теста — `after1` и `after2`.
Три теста проверяют сумму и умножение. Четвёртый специально делит на ноль, чтобы показать падение.

`Main` вызывает `TestRunner.run(MyClassTest.class)`.

`TestRunner` состояния не хранит. Метод `run` ищет методы по аннотациям, потом для каждого теста делает новый объект `MyClassTest` и вызывает сначала все `@Before`, потом сам `@Test`, потом все `@After`. Если один тест упал, остальные всё равно выполняются.

`findMethods` собирает методы с нужной аннотацией и сортирует их по имени, чтобы `before1` шёл раньше `before2`.

`callMethod` вызывает метод через `invoke`. Если внутри было исключение, оно ловится, пишется в лог, и метод возвращает `false`.

`printStatistics` печатает статистику: сколько прошло, сколько упало и сколько всего.
